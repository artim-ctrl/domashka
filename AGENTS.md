# AGENTS.md

Домашка по русскому для испаноговорящих. Пока одна страница — таблица русских звуков: у каждого
звука и слова кнопка с записью. Будут и другие разделы домашки, так что код и контент
рассчитывай на рост.

Пользователь — автор и учитель, пишет по-русски. Отвечай по-русски, комментарии в коде и
сообщения коммитов тоже по-русски, в духе уже существующих.

## Устройство

```
server/                Go, без внешних зависимостей
  main.go              флаги, запуск, обработчики /api/page, /api/audio и админки
  routes.go            маршруты, префикс BASE_PATH, CSP и заголовки, защита админки (adminGuard)
  content.go           модель страницы, Text на трёх языках, проверка контента при старте
  content/page.json    весь текст страницы (вшивается через go:embed)
  content/speech.json  что говорить синтезатору для каждой записи, «+» — ударение
  audio.go             папка записей: поиск файла по ключу, нормализация имён
  tts.go               голоса и движки: Silero (через tools/tts.py) и macOS say
  candidates.go        варианты озвучки и выбор записи (audio/choices.json)
tools/tts.py           процесс-синтезатор Silero; сервер запускает его через `uv run --script`
web/                   React 19 + Vite + TypeScript, без роутера (одна страница)
  src/i18n.tsx         языки интерфейса и все надписи
  src/admin/           админка озвучки
audio/                 записи (.m4a) и choices.json — в git
candidates/            варианты озвучки — не в git
```

## Команды

Только через `Makefile` (`make help`):

- `make api` — сервер на :8080 **с админкой** (`-admin`); `make web` — Vite на :5180 с прокси `/api`.
- `make check` — `go vet`, `go test` и проверка типов фронта. Гоняй после любых правок.
- `make missing` — каких записей нет; `make voices` — заранее сделать варианты озвучки.
- `make docker-up` / `make docker-down` — прод-образ через compose локально.
- `make deploy SERVER=user@host` — выкатить на сервер (`deploy/deploy.sh`: сборка здесь, образ
  по ssh, на сервере только Docker). Это действие на проде — только по просьбе пользователя.

Порт 5173 на машине занят чужим контейнером — не возвращай Vite на него.

## Контент

- Строки в `page.json` — либо просто строка (одинаковая на всех языках), либо объект
  `{"es": …, "en": …, "ru": …}`. Новый текст пиши сразу на трёх языках.
- Разметка в строках: `**жирный**`, `*курсив*`, `{{s:ш}}` — кнопка звука, `{{w:дом}}` — слова,
  `{{w:молоко|молоко́}}` — ключ записи и подпись.
- Сервер не стартует (и `make check` падает), если: нет перевода, в переводе другие кнопки
  `{{…}}`, для записи со страницы нет строки в `speech.json` или слово там с опечаткой.
- Новое слово или звук на странице ⇒ добавь строку в `speech.json` с ударением (`к+ошка`).

## Озвучка

Записи генерируются синтезатором, а выбирает их человек в админке: `localStorage.is_admin = "true"`
+ сервер с `-admin`; клик по звуку открывает панель с вариантами 10 голосов, «Выбрать» пишет
`audio/<sounds|words>/<ключ>.m4a` и `audio/choices.json`.

- **Не перезаписывай `audio/` и `choices.json` сам** — это выбор пользователя на слух.
  Варианты в `candidates/` можно генерировать свободно.
- Страницу записи своим голосом (`/record`) пользователь попросил удалить — не предлагай снова.
- Одиночную согласную синтезаторы читают названием буквы («ш» → «ша»). Поэтому в `speech.json`
  протяжные ж з с ф х ш щ записаны утроенной буквой (`шшш`), прочие согласные — слогом (`б+а`).
  Пользователь может выбрать и другое (например, `+эс`) — это его решение.
- Silero не принимает строку из одной «ё» (её нет в диапазоне `а-я`): `tools/tts.py` подменяет её
  на «йо». Похожие падения с пустым `ValueError` ищи в предобработке текста Silero.
- Лицензии: Silero v5_5_ru — CC BY-NC (только некоммерчески), Silero CIS — MIT, но дикторы
  из других языков СНГ. Если речь о деньгах — напомни об этом.
- Модели Silero лежат в `~/.cache/domashka/silero`; окружение Python собирает `uv` сам.
- `say` и `afconvert` есть только на macOS — админка и генерация работают только там.

## Прод

`Dockerfile` собирает образ из сервера, `web/dist` и `audio/` (distroless, не root, ~10 МБ,
базовые образы по digest). Админки, синтезатора и `candidates/` в образе нет и быть не должно.
При сборке гоняются тесты сервера. Сервер завершается штатно по SIGTERM; `/healthz` +
`-healthcheck` — для Docker. Прод: `example.com/domashka/` за nginx хоста; фрагмент конфига —
`deploy/nginx.conf` (путь пересылается как есть, сжатие JS/CSS/JSON там же — Go не сжимает).

## Безопасность

Прод открыт в интернет, админка — только локально. Правила, которые легко нечаянно сломать:

- Интерфейс живёт под префиксом (`BASE_PATH=/domashka`). Все адреса во фронте и в ответах
  сервера — **относительные** (`api/page`, `api/audio/…`), Vite собирает с `base: "./"`.
  Абсолютный `/api/...` сломает прод.
- Путь к файлу строится только из ключей страницы (`FindClip`, скан папки), никогда из адреса.
- Новые админские ручки — только внутри `if s.admin` в `routes.go`; их закрывает `adminGuard`
  (localhost, свой Origin, `Content-Type: application/json`). Фронт шлёт JSON — так и оставь.
- CSP (`routes.go`): только `'self'`, встроенный скрипт — по хэшу. Новый inline-скрипт или
  стиль, сторонний шрифт или CDN — сначала подумай, нужен ли, потом правь CSP и тест.
- Новая модель Silero — только с SHA-256 в `MODELS` (`tools/tts.py`).
- `server/security_test.go` — регрессии безопасности; не ослабляй их, чтобы прошли.

## Проверка

- После правок — `make check`.
- Интерфейс проверяй в настоящем браузере (headless Chrome + CDP) на **копии** `audio/`
  и отдельных портах (`-addr`, `-audio`, `-candidates`): у пользователя могут быть запущены
  `make api`/`make web` из Pitwall — не убивай их без спроса, а если надо остановить — штатно (SIGINT).
- Vite слушает только `[::1]`: стучись на `localhost`, не на `127.0.0.1`.
- Docker-контейнеры с данными не удаляй (`compose down`) без спроса: у соседних проектов
  данные бывают в анонимных томах.
